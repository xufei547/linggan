# 灵感收纳盒 · Linggan Box

给写歌的人收纳哼唱灵感的 iPhone 应用。哼一段，别丢了。

**[产品主页](https://xufei547.github.io/linggan/)** · **[隐私政策](https://xufei547.github.io/linggan/privacy.html)**

- 锁屏 / 控制中心 / Siri / 操作按钮一步开录，后台持续录音
- **哼唱找回**：把那句再哼一遍，按旋律相似度搜回自己的录音库（YIN 音高 + DTW，全在本机算）
- 音高曲线：看清哼的是哪几个音
- 全量备份导出，防误删防换机
- 完全离线：无服务器、无账号、无广告、无追踪。录音只存在你自己的设备上。

本仓库只托管产品主页与隐私政策。
